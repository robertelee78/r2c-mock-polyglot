# Web-framework fixtures (r2c O-84)

Source-real framework code for r2c's Stage-5 web-family measurements:
cross-site scripting output bypass, CSRF on ambient-credential state changes,
dynamic redirect targets, authorization-requirement enforcement, explicit
session-cookie settings, credentialed CORS policy and request-object binding
into protected state.

| Directory | Frameworks | Languages |
|-----------|------------|-----------|
| `python/` | Django (+ DRF, django-cors-headers), Flask (+ Blueprint, Flask-WTF, Flask-Cors, Flask-Principal), FastAPI, APIRouter, Starlette | Python, Django/Jinja templates, JSON settings |
| `node/` | Express, NestJS (Express, Fastify, GraphQL), Next.js (pages API, app routes, Server Actions) | JavaScript, TypeScript, TSX, EJS/Pug/Handlebars, JSON/YAML settings |
| `jvm/` | Spring MVC and WebFlux with Spring Security | Java, Kotlin, Thymeleaf, YAML/JSON/XML/properties settings |
| `dotnet/` | ASP.NET Core MVC, Razor Pages, minimal APIs and route groups | C#, Razor, JSON settings |
| `go/` | Gin, Echo, Chi | Go, `html/template` and `text/template`, JSON settings |

Each framework area holds three kinds of case for every applicable family: a
positive shape, a directly recognized correct use, and an identified but
unresolved question (an opaque helper, configuration or policy). The
expected source observations and their exact operation anchors live outside
this repository, in r2c's frozen O-84 dataset, so no expectation is copied
into the scanned target.

These directories are scanner-evaluation fixtures. Do not deploy or run them.
Their package manifests pin real framework versions; the lock files
(`node/package-lock.json`, `python/uv.lock`, `go/go.sum`) were generated by
the ecosystems' own tools without executing package code.
